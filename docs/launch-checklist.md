# Launch checklist

## From the client
- [ ] Approval of the C2 design (or the list of changes)
- [ ] Cities and counties served
- [ ] Email address to list on the site
- [ ] Hours. The site currently says evening and weekend appointments are available.
- [ ] Logo as a vector file (SVG, EPS or AI). The current PNG is 348px square.
- [ ] Confirm: copies of credentials are available to title companies and law firms on request
- [ ] Confirm: proof of service is returned after process serving
- [ ] Confirm: you call back to confirm a time after a request
- [ ] Domain name, and who controls its DNS
- [ ] Where form requests should go (email address or phone for text alerts)
- [ ] Signed agreement and payment terms

## Before going live
- [ ] Every [placeholder] replaced (search the code for "[")
- [ ] Google review count updated, or a plan for keeping it current
- [ ] Form submits successfully, and the success and error messages show
- [ ] Launch build deployed: no ribbon, no watermark, no noindex
- [ ] Access turned off and the domain connected over HTTPS
- [ ] Canonical, Open Graph and JSON-LD URLs point at the real domain
- [ ] Tested on a real iPhone and a real Android phone: tap-to-call works from the hero number and the sticky bar
- [ ] Lighthouse (mobile): Accessibility 100, SEO 100, Performance 90+
- [ ] Site link added to the Google Business Profile
